# 门店标签字段说明（归一门店维度）

> 对应文件：`永辉门店标签_归一门店.csv`
> 数据粒度：一行 = 一家归一门店（跨平台拉通后的实体店）
> 共 43 字段，分三组：统一门店维度（11）、A组自定义标签（13）、B组品牌活动标签（19）

---

## 一、统一门店维度（11 字段）

| # | 字段名 | 中文名 | 定义 / 口径 |
|---|--------|--------|-------------|
| 1 | `sg_store_id` | 统一门店ID | Storeverse 归一门店主键（storeverse_sg_store.id），跨平台唯一标识一家实体店 |
| 2 | `sg_store_name` | 统一门店名 | 归一门店名（storeverse_sg_store.store_name），如「永辉超市(南岸万达广场店)」 |
| 3 | `sg_retail_id` | 统一零售商ID | Storeverse 统一零售商主键（storeverse_sg_store.sg_retail_id） |
| 4 | `sg_retailer_name` | 统一零售商名 | 归一零售商名（storeverse_sg_retail.cn_name），如「永辉超市」 |
| 5 | `sg_business_type` | 业态 | 大型商超 / 连锁便利店 / 等 |
| 6 | `province` | 省 | 统一门店所在省 |
| 7 | `city` | 市 | 统一门店所在市 |
| 8 | `district` | 区县 | 统一门店所在区县 |
| 9 | `address` | 门店地址 | 统一门店详细地址 |
| 10 | `platform_cnt` | 覆盖平台数 | 该店出现的平台数（datasource 去重），1=单平台、≥2=跨平台归一并 |
| 11 | `platforms` | 覆盖平台列表 | 逗号分隔的平台清单，如「到家-淘宝闪购,到家-美团闪购」 |

| 43 | `b16_post_compete` | 近30天海报竞品SKU数量 | 海报全部品牌 SKU（不切割本品/竞品） |

## 附：空值说明

| 字段 | 空值原因 |
|------|---------|
| `a10_24h` | 营业时间字段覆盖仅 0.9%，无可靠数据 |
| `b6_mech_store` | 到店门店映射覆盖极低（微信29/支付宝109），且支付宝券名待补 |
| `b10_aov_store` | 该店无到店订单（永辉归一门店均为到家平台） |
| `b12_sku_act_store` | 到店券平台无 SKU 粒度 |
| `b14_sku_combo` | 需订单级共现数据，未实现 |
| `b8/b9_top_sku_name` | 供给表无对应 upc 的名称记录 |
