## 2026-09-11 增加登录页，首页改统计入口，门店页信息架构调整

### 用户原话

「一、缺一个登录页；首页修改：1、删除把到家订单…的那句话；2、图1 改成登陆用户的访店统计和销售统计，点击查看明细，筛选按钮：到店 到家，昨日访店数/活动GMV/补贴金额/ROI；3、门店标签页面筛选按钮 1KM、3KM，标签改成显示社区数、医院数、学校数、商业中心数、同类商超数，图2、图3 删除这个统计；4、到家平台能力改成活动统计」

### 对齐结论

- 登录方式：工号 + 密码，演示环境预填，不做真实鉴权
- 首页 = 原角色选择页改造：顶部统计卡，下方保留 DSR / 总部 / 导购 三个入口
- 周边数量：业态有无沿用真实标签，1KM/3KM 数量为演示估算并在卡片上标注
- 图2 的 POI 明细列表、图3 的 4 格指标（到家 ROI / 笔单价 / 在售 SKU / 最优机制）一并删除
- 活动统计按活动维度列 GMV / 补贴 / ROI / 投放天数，原「机制效果」模块合并进来

### 产出

- 新增 `src/screens/Login.tsx`、`src/screens/Home.tsx`、`src/screens/StatsDetail.tsx`
- 新增 `src/data/account.ts`：登录用户、到店/到家渠道汇总、访店明细
- 删除 `src/screens/RoleSelect.tsx`
- 数据契约：`Store` 增 `poiCounts`、`platformsUncovered`，`SalesSlice` 由 `platforms + topSkus + mechanisms` 改为 `topSkus + campaigns`
- 到店渠道走空态：永辉样例门店到店能力标签均为「否」，不编造到店 GMV

## 2026-09-11 原型 UI 规范审查与修复

### 用户原话

「你再审查一下UI，看还有没有可以优化的点，避免UI表达不规范，排版错位等情况」

### 排版类修复

- `.sku-line` / `.store-mini` / `.metric` 补 `min-width:0` 与 `overflow-wrap`，右侧标签 `flex-shrink:0`，长门店名与长 SKU 名不再挤压变形
- `.live-row` 允许换行，`.section-title` 补 gap 并限制右侧副标题
- 相机取景框由 2 个角标补齐为 4 个；快门两侧改为等宽，真正居中
- 门头插画重排：招牌落进雨棚色带，补地面分界；扫描线层级提到遮罩之上
- 4 格指标卡改 flex 底对齐，中文值用 `.metric b.text` 降一档字号
- 隐藏滚动条，补 `:active` / `:focus-visible` / `:disabled` 反馈

### 表达类修复

- 去掉界面上的内部字段名与原始记法：`a11_peak_weekday`、`POI=是`、`到家能力=否`、`覆盖平台列表=`
- 未覆盖平台不再显示一排「—」，改为一句说明
- 机制状态错字「OI 差」修正为「ROI 偏低」
- 「本店可行动空间」与 ROI 数值语义不符，改为「本店抓手 + 一句话动作」
- 首页宣称的「微信 / 京东到家 / 美团」与实际数据不符，改为淘宝闪购 / 京东秒送 / 美团闪购
- DSR 片区（海淀）与相机 HUD 坐标（北京）与样例门店（重庆）不符，已对齐
- 导购端昨日笔单价误用涨跌绿色，改中性标签
- 统一时段与相对日期写法：`下午 14:00-17:59`、`近 30 天`
- 页脚中文不再用等宽字体，仅 ID 用 `<code>`

### 代码清理

- 删除未渲染字段：`connectId`、`type`、`PlatformStat.delta/up`、`TopSku.price/subsidy`、`yesterdayUp`
- 删除失效样式 `.todo` / `.check`、未引用图标 `IconThumbUp` / `IconThumbDown`、`PhoneFrame` 的 `dark` 死参数

### 验证

- 390px 与 360px 两种宽度下，全部 7 屏无横向溢出、无越框元素
- `tsc` 与 `vite build` 通过

- 用户：一线（DSR、销售主管、导购），不是总部
- 形态：手机端场景答案，不是后台报表
