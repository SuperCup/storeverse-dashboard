## 2026-09-08 将面聊概述整理为 PRD

### 用户原话摘要

用户提供面聊概述，要求整理成 PRD。面聊围绕「利用门店颗粒度数据赋能一线人员」，覆盖 DSR 跑店、导购两个场景，以及平台能力与价值。

### 输入要点

- 入口：拍照识别门店 + Connect ID
- 输出：门店画像、销售事实、行动建议（上架、补货、促销）
- DSR：到店拍照 → 拉到店到家数据 → 机会点（缺货、应上未上）；可结合周边环境给备货建议
- 导购：看本店数字化经营结果（活动效果、热销 SKU），用于推券和推荐
- 用户：一线（DSR、销售主管、导购），不是总部
- 形态：手机端场景答案，不是后台报表

### 产出

- `docs/PRD-门店颗粒度一线赋能.md`（v0.1 草案）
